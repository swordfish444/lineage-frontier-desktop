# Lineage Frontier desktop app

**Download: https://lineage-frontier.com/download/**

This repository hosts the installers and the update feed of the Lineage Frontier desktop app for macOS and Windows.
The app opens the live game at [lineage-frontier.com](https://lineage-frontier.com/), so game updates arrive the
moment they are released, with no download. The app checks this repository's latest release when it starts and every
few hours, downloads a newer version of itself in the background and installs it when you restart.

## Installing

The app is not yet signed by Apple or Microsoft, so each system asks once before the first launch.

- **Mac:** open the downloaded file and drag Lineage Frontier into Applications. Open it; when macOS says it cannot
  check the app for malicious software, choose Done, then open System Settings › Privacy & Security, find "Lineage
  Frontier was blocked" and choose Open Anyway. Later updates install by themselves.
- **Windows:** run the installer. If Windows says it protected your PC, choose More info, then Run anyway. The app
  installs for your Windows user and adds Start menu and desktop shortcuts.

Sign in with Google from the app: it opens your web browser, and after you sign in there you return to the app with the
same account characters as on the web.
